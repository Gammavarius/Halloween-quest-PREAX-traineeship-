# 🎪 Легенда бродячего цирка (Halloween Quest)

Интерактивный текстовый квест с развилками, системой инвентаря и несколькими концовками, созданный в рамках стажировки Preax.

**[🎮 Играть в демо](https://halloweenquest.vercel.app/)**

## 📖 О проекте

Это браузерная игра-квест, где игроку предстоит исследовать таинственный бродячий цирк, принимать решения, собирать предметы и найти одну из 4 концовок. Вся логика игры (сцены, переходы, условия) управляется через JSON-файл.

### ✨ Реализованный функционал:

- **Игровой движок:** динамическая смена сцен, обработка выборов и концовок на основе JSON.
- **Система инвентаря:** сбор предметов (билет, маска, ключ) и открытие скрытых веток сюжета при их наличии.
- **Роутинг:** навигация между экранами сцены и финала с сохранением истории браузера (React Router).
- **Адаптивная верстка:** интерфейс корректно отображается на десктопах (1920px), планшетах (1024px, 768px) и мобильных устройствах (375px).
- **Дизайн-система:** использование CSS-переменных, вынесенных из макета Figma (цвета, типографика, отступы).

## 🛠 Стек технологий

- **React** (Vite) - основа приложения.
- **React Router DOM** - маршрутизация (SPA).
- **React Context API** - управление глобальным состоянием инвентаря.
- **CSS Modules** - изолированная стилизация компонентов без конфликтов классов.
- **CSS Variables** - токены дизайн-системы (цвета, шрифты, размеры).
- **Алиасы путей** - настроены в `vite.config.js` для чистых импортов (например, `@/components`).

## 🚀 Установка и запуск (локально)

Если вы хотите запустить проект на своем компьютере, выполните следующие шаги:

1. **Клонируйте репозиторий:**

```bash
   git clone https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПОЗИТОРИЙ.git
   Перейдите в папку проекта:

cd ТВОЙ_РЕПОЗИТОРИЙ
Установите зависимости:

npm install
Создайте файл .env в корне проекта и добавьте в него переменную для загрузки картинок:

VITE_IMG_API=https://filestore.preax.ru/file?id=

Запустите сервер разработки:

npm run dev
Откройте игру: перейдите по адресу http://localhost:5173 в вашем браузере.
```
